# Stalker Mod

This mod adds a terrifying entity known as the "Horror Steve" and a deadly "Red Night" event.

## Features
* **Horror Steve**: A relentless stalker that watches you from a distance and slowly approaches when you aren't looking.
* **Red Night**: A blood-red night where regular monsters are empowered, Withers may spawn naturally, and sleep is impossible.
* **Skinwalker**: Fake entities that look like players but act unnaturally.
